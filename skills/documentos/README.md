# Documentos

Skills para leer, resumir y analizar documentación técnica: planos, informes, pliegos, manuales y certificados.

## Skills

| Skill | Qué hace | Estado |
|---|---|---|
| analisis-documentos-tecnicos | Extrae datos clave, detecta inconsistencias y genera un resumen para técnicos. | planificada |

## Cómo se combinan

Los resultados del análisis pueden alimentar otras skills, por ejemplo la descripción técnica de una propiedad en [inmobiliaria](../inmobiliaria/).
