# Inmobiliaria

Skills para el trabajo diario de un agente o corredor inmobiliario: documentación de captación, fichas de propiedades y trámites con propietarios.

## Skills

| Skill | Qué hace | Estado |
|---|---|---|
| [autorizacion-de-venta](autorizacion-de-venta/) | Genera el borrador de una autorización de venta a partir de fotos de DNI, escritura y datos de la propiedad. | beta |

## Cómo se combinan

Flujo de captación típico:

1. **autorizacion-de-venta** → documento para que firme el propietario.
2. **limpieza-fotos-propiedad** ([imagenes](../imagenes/)) → fotos listas para el portal.
3. **publicaciones-meta** ([marketing](../marketing/)) → anuncio para Facebook e Instagram.

## Aviso

Los documentos generados son borradores. Deben ajustarse a la normativa de tu jurisdicción y a los modelos de tu colegio profesional, y ser revisados por un corredor matriculado.
