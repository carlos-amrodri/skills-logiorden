# Imágenes

Skills para preparar imágenes antes de publicarlas: limpieza de ambientes, retoques y adaptación de formatos.

## Skills

| Skill | Qué hace | Estado |
|---|---|---|
| limpieza-fotos-propiedad | Quita muebles, ropa y basura de fotos de ambientes para publicarlas limpias. | planificada |

## Compatibilidad general

Editar imágenes requiere que la IA pueda **generar o modificar imágenes**:

- **ChatGPT:** puede hacerlo de forma nativa.
- **Claude:** no genera imágenes; las skills de esta temática indican si necesitan un script con una API externa o si funcionan solo en ChatGPT.

## Buenas prácticas

- Avisar en la publicación cuando una foto fue editada digitalmente (amoblamiento o limpieza virtual).
- No alterar elementos estructurales (paredes, ventanas, pisos, vistas): solo objetos sueltos.
