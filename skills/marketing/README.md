# Marketing

Skills para entender al cliente y comunicar: definición de buyer personas, contenido para redes y publicaciones en Meta (Facebook e Instagram).

## Skills

| Skill | Qué hace | Estado |
|---|---|---|
| buyer-persona | Descubre y documenta buyer personas a partir de datos del negocio y sus clientes. | planificada |
| publicaciones-meta | Genera textos, segmentación y calendario de publicaciones para Facebook e Instagram. | planificada |

## Cómo se combinan

1. **buyer-persona** → a quién le hablamos.
2. **publicaciones-meta** → qué publicamos, para cada persona.

## Nota sobre publicar

Las skills generan el contenido listo para usar. Publicar automáticamente en Meta requiere un conector o la API de Meta configurados en tu plataforma; sin eso, el contenido se copia y publica a mano.
